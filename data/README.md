# Data

No patient data is stored in this repository.

## Expected layout (create locally)

```
data/
├── raw/
│   ├── tb/        # cough .wav files labelled TB-positive
│   └── non_tb/    # cough .wav files from non-TB subjects
├── features/      # generated by feature_extraction.py
└── sample/        # a few public/demo clips only
```

## Sources

Use only datasets you are permitted to use, and cite them here. Publicly available cough datasets include COUGHVID and Coswara (mainly COVID-oriented). Check each dataset's licence and whether TB-labelled data is available for your purpose.

## Rules

- Never upload identifiable patient data
- Real recordings need informed consent and ethical approval
- Files over 25 MB: share a Drive link instead of uploading
